# MutqinSpace — Frontend (PWA)

Sistem mutaba'ah hafalan Al-Qur'an: setoran ziyadah & murojaah, presensi halaqah, portal wali, dashboard capaian, notifikasi WhatsApp.

- Backend: Google Apps Script (REST API JSON) + Google Sheets — kode di folder `backend/` paket instalasi.
- Satu-satunya konfigurasi: `js/config.js` → `GAS_URL` (URL Web App `/exec`). URL ini bukan rahasia.
- `demo.html` menjalankan aplikasi dengan data contoh di browser (tanpa server). Hapus `demo.html` dan `js/demo-backend.js` bila tidak ingin mode demo ikut terpublikasi.
- Panduan lengkap: `PANDUAN-INSTALASI.md`.
